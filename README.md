# Bank Teller 🏦

![Go Version](https://img.shields.io/badge/Golang-1.24-66ADD8?style=for-the-badge&logo=go)
![Repo Size](https://img.shields.io/github/repo-size/mohammadne/bank-teller?logo=github&style=for-the-badge)

Bank Teller is a minimal Go project that simulates the core functionalities of a bank teller system. It provides basic operations to manage users and their transactions.

## Features ✨

- List users
- Make transactions between users
- Update transaction status (e.g., success, failed, pending)
- List all transactions
- Built with Go (Golang) — lightweight and efficient
